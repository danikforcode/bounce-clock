# bounce-clock 0.0.2

Claude и идея Даниила Кочубейника

## Движок
- Виртуальный холст: не меньше 80×48 пикселей, целочисленный масштаб K.
- Холст заполняет весь терминал, рамки нет.
- Вывод только символами ▀▄█ — одинаково везде, включая Linux VT.
- Отрисовка по изменениям: в покое 2 пробуждения в секунду, в движении до fps_max.
- Только изменившиеся символы, synchronized output.

## Часы
- Шрифт 4×7, рамка (опционально), дизеринговая тень (опционально).
- Переходы цифр: morph, roll, dissolve, drop, instant — отдельно для часов, минут, секунд.

## Режимы
- bounce: DVD-отскок, hit-stop, squash, частицы, попадание в угол.
- static: пружина к позиции (центр, стороны, углы).
- manual: стрелки толкают с инерцией, Shift+стрелки — сдвиг на пиксель.
- Переходы анимированные: торможение, приседание и «выстрел», сохранение инерции.

## Конфигурация
- ~/.config/bounce-clock/config.toml (Windows: %APPDATA%\bounce-clock).
- Единый реестр параметров: конфиг, окно настроек и проверка значений из одного описания.
- Профили, расписание [[schedule]], события [[event]], заставка по простою.
- Горячая перезагрузка раз в 2 секунды, ошибки не роняют программу.
- Окно настроек (Tab) сохраняет в tuned.toml поверх config.toml.

## Эффекты
- Сборка из пикселей при запуске, осыпание при выходе.
